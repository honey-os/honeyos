How it works

From deployment to detection in four steps. No security expertise required.

01

Deploy

Flash a Raspberry Pi image or run a single Docker command. HoneyOS is up and running in under five minutes with zero configuration.

02

Deceive

Fake SSH servers, HTTP admin panels, databases, and file shares appear on your network. They look real to scanners and attackers.

03

Detect

Any connection to a honeypot triggers an instant alert. No legitimate user has a reason to touch these services — every hit is suspicious.

04

Respond

Review full session recordings, analyze attacker commands, and export evidence. Know exactly what happened and how far they got.

Deploy anywhere

Two deployment options. Both take under five minutes. Both run fully offline.

Raspberry Pi

Dedicated hardware appliance. Flash, plug in, and forget. Appears as a separate device on your network with its own IP.

$ curl -sSL https://honeyos.io/setup-pi.sh | bash
# Access at http://honeyos.local:7777

Docker

Run on any Linux host, VM, or NAS. Single compose file with all services included. Works on x86 and ARM.

$ curl -sSL https://honeyos.io/setup-docker.sh | bash
# Access at http://localhost:7777
